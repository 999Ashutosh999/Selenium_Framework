# Selenium Pytest Automation Framework

> A scalable, maintainable, and production-ready test automation framework built using **Python, Selenium WebDriver, and Pytest**, following industry best practices.

---

# Project Overview

This project demonstrates my ability to design and implement a robust Selenium-based automation framework from scratch using Python and Pytest.

The framework is designed to support:

* Cross-browser test execution
* Scalable test architecture
* Clean and maintainable code structure
* Industry-standard automation practices

It follows a modular approach to ensure easy extensibility and long-term maintainability.

# Installation and Setup

## Clone the repository

```
git clone https://github.com/999Ashutosh999/Selenium_Framework.git
```

## Navigate to project folder

```
cd Selenium_Framework
```

## Install dependencies

```
pip install -r requirements.txt
```

---

# How to Execute Tests

Run all tests:

```
pytest
```

Run tests with HTML report:

```
pytest --html=reports/report.html
```
